# Data

All data in this folder is synthetic, generated by `scripts/generate_data.py`.

- `dev.jsonl` — 90 trajectories for development.
- `held_out.jsonl` — 30 trajectories for evaluation, never used to tune the rules.

Each row has a `synthetic` flag set to true, a gold label
(`gold_defective`, `gold_defect_types`, `gold_rubric`), a
fictional vendor (`Vendor-A`, `Vendor-B`, or `Vendor-C`), and
a task with tool steps. Planted defects are of known types, so
the evaluation can be checked against the gold labels.

Regenerate with: `python scripts/generate_data.py`
